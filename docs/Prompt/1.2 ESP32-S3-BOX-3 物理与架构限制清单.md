# ESP32-S3-BOX-3 物理与架构限制清单 (Hard Constraints Manifesto)

### 1. 总线带宽红线 (Bus Limitations)

_在此频率之上，通信稳定性无法根据提供的文档得到保证。_

- **屏幕 SPI 速率 (Display SPI):**
    
    - **理论上限**: **10 MHz** (写操作) / **6.6 MHz** (读操作)。
    - **依据**: 根据 ILI9341 数据手册，串行接口（Serial Interface）的“写时钟周期 (Write Cycle)”最小为 **100 ns** ($1/100ns = 10 MHz$)；“读时钟周期 (Read Cycle)”最小为 **150 ns** ($1/150ns \approx 6.6 MHz$)。
    - **架构提示**: 虽然 ESP32-S3 的 SPI 控制器支持更高频率，但受限于 ILI9341 的规格书参数，高速刷屏（如 >30fps 全屏刷新）可能面临显示控制器端的时序瓶颈。
- **公共 I2C 总线 (Sensor/Touch/Audio):**
    
    - **速率上限**: **400 kHz** (Fast Mode)。
    - **短板设备**: 虽然 ICM-42607-P 支持 1 MHz (Fast-Mode Plus)，但同总线上的音频 ADC **ES7210** 数据手册明确指出其 I2C 接口最大速率为 **400 kbps**。
    - **依据**: I2C 总线速度必须迁就总线上的最慢设备。

### 2. 电源与热 (Power & Thermal)

_超出此范围可能导致 LDO 保护关断或系统重启。_

- **3.3V 主供电能力**:
    
    - **源端芯片**: SY8088AAC (U1, U2, U3)。
    - **最大输出电流**: **1.0 A**。
    - **系统基础负载**:
        - ESP32-S3 (RF 发射峰值): **~344 mA** (Bluetooth LE @ 20dBm)。
        - 音频 Codec/ADC/Mic: 约 10-20 mA。
        - LCD 逻辑与背光 (由 ETA1611 升压，但源自 3.3V/5V): 原理图标注背光电流 20mA。
    - **安全裕量 (Headroom)**: 约 **500 mA**。
    - **警示**: 若通过 Sensor Header 或 PMOD 外接高功耗设备（如大功率舵机、激光雷达），必须严格计算电流，避免超过 1A 总限额导致 3.3V 塌陷。
- **电池充电限制**:
    
    - **充电电流**: **500 mA**。
    - **依据**: SENSOR-01 板上的充电芯片 AP5056 (U2) 通过电阻 R10 (2KΩ) 设定。原理图明确注释 "R10=2K, Ibat=500mA"。
- **USB 外设供电 (Dock Board):**
    
    - **限流阈值**: **~402 mA**。
    - **依据**: DOCK 扩展板使用 SY6280AAC (U1) 作为限流开关，限流电阻 R8 为 16.9 kΩ。根据公式 $I_{lim} = 6800 / R_{set}$，计算得出 $6800 / 16900 \approx 0.402 A$。

### 3. IO 独占与复用 (IO Mux & Conflicts)

_触碰这些引脚可能导致启动失败或功能异常。_

- **Strap Pins (启动控制脚) 风险分析**:
    
    - **GPIO 0 (Boot)**: 原理图上连接了 Boot 按键，有 R16 (1K) 上拉。
        - _风险_: 用户在复位时若误按 Boot 键，将进入下载模式。
    - **GPIO 3 (JTAG)**: 在主板原理图上连接到 IO3 网络，最终引出至 PMOD 接头。
        - _风险_: 默认浮空。若外部电路在启动时将其拉低/拉高，可能影响 JTAG 调试功能的启用。
    - **GPIO 45 (VDD_SPI)**: 模组内部决定 Flash 电压。原理图上未见外部强拉。
        - _风险_: 严禁外部电路将其拉高，否则可能导致 VDD_SPI 电压错误（ESP32-S3R16V 需 1.8V），烧毁 Flash 或无法启动。
    - **GPIO 46 (ROM Log)**:
        - _连接_: 原理图中 pin 16 (IO46) 未连接到明显的外部下拉电阻，依靠芯片内部下拉。
        - _风险_: 如果在 PMOD 或 Sensor 接口上外接了默认输出高电平的设备，会导致 ROM 日志打印被禁用或进入错误的 Boot 模式。
- **物理遮挡 (Mechanical Blockage)**:
    
    - **USB-C (Dock)**: 用于供电和数据。
    - **PMOD x2**: 位于 Dock 板侧面。
    - **被遮挡风险**: 如果安装了外壳，主板上的 **FPC 连接器 (LCD, Touch, Camera)** 将无法访问。仅 Dock 板上的 USB 和 PMOD 接口是对外暴露的。

### 4. 存储与启动 (Storage)

_决定了哪些 GPIO 绝对不可用。_

- **Flash 与 PSRAM 架构**:
    - **模组型号**: ESP32-S3-WROOM-1-N16R16VA。
    - **Flash 类型**: **Quad SPI (16 MB)**。
    - **PSRAM 类型**: **Octal SPI (16 MB)**。
- **引脚占用红线**:
    - 由于使用了 **Octal (8线) PSRAM**，以下 GPIO 被模组内部的存储器独占，**严禁**用于任何外部功能：
        - **GPIO 33** (SPIIO4)
        - **GPIO 34** (SPIIO5)
        - **GPIO 35** (SPIIO6)
        - **GPIO 36** (SPIIO7)
        - **GPIO 37** (SPIDQS)
    - **依据**: ESP32-S3 Datasheet 明确指出，对于嵌入 Octal SPI PSRAM 的模组，IO35-IO37 连接到 PSRAM 且不可用于其他用途。同时 N16R16VA 型号为了支持 16MB PSRAM，必须使用 Octal 模式。
