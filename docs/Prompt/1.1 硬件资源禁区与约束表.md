这是一份基于 **ESP32-S3-BOX-3** 原理图及 **ESP32-S3** 数据手册整理的《资源分配与禁区表》。此表旨在用于硬件审核，防止资源冲突。

### 核心策略说明

1. **绝对禁区 (Blacklist)**：硬件上已连接内部 Flash/PSRAM 或关键系统功能的引脚，严禁复用。
2. **高危区 (High Risk)**：Strapping 管脚（启动控制脚），外部电路必须严格遵守上下拉要求，否则导致启动失败。
3. **条件复用区 (Conditional)**：已被板载外设（LCD, Audio）使用的引脚，除非您明确知道自己在修改该外设驱动，否则不要占用。
4. **扩展区 (Expansion)**：引出至 PMOD 或排针的引脚，需根据连接的扩展板（Sensor/Dock）判断占用情况。

### 硬件审核 Checkpoints (MECE原则)

在进行硬件连接审核时，请依次确认以下几点：

1. **禁区规避 (Blacklist Check)**：
    
    - [ ] 确认 GPIO 26 ~ 37 完全未连接任何外部线路。
    - [ ] 确认 GPIO 19, 20 未被用作普通 I/O (除非完全放弃 USB 功能)。
2. **Strapping 安全 (Strapping Safety)**：
    
    - [ ] **GPIO 0, 45, 46, 3**：确认连接的外部设备在上电瞬间（Boot阶段）不会强制改变这些引脚的默认电平（0 需高，45/46 需低）。
    - [ ] 特别注意 **GPIO 46**，它在 BOX-3 上控制 PA，如果外接设备将其强拉高，可能导致上电进入错误的 Boot 模式或 LOG 打印异常。
3. **总线冲突 (Bus Conflict)**：
    
    - [ ] **I2C (IO40/41)**：若外接 I2C 设备，确认地址不为 **0x68 (IMU), 0x18 (Codec), 0x41 (ADC), 0x14/0x5D (Touch), 0x38 (AHT30)**。
    - [ ] **SPI (LCD)**：IO 4, 5, 6, 7, 48 被屏幕占用，如需使用 PMOD 接口，需确认是否与屏幕驱动冲突（Dock 板引出了这些脚）。
4. **配件特有冲突 (Accessory Conflict)**：
    
    - [ ] **Sensor Board**：若使用 Sensor 扩展板，**IO 38 (Radar), IO 39 (IR TX), IO 10-14 (SD/ADC)** 将被占用，不可用于其他用途。
    - [ ] **Dock Board**：PMOD 接口复用了部分 LCD 引脚 (IO4-7)，需软件分时复用或二选一。
