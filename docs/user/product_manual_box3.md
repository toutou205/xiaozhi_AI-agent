# ESP32-S3-BOX-3 (小智 AI 助手) 产品说明书

## 1. 基础操作 (Basic Operation)

### 1.1 唤醒词 (Wake Word)
*   **唤醒口令**: **“你好小益”** (Ni Hao Xiao Yi)
*   **操作方式**: 对着设备清晰说出“你好小益”，设备识别成功后屏幕会显示“正在聆听”图标，此时您可以直接说出您的指令。

### 1.2 物理按键功能 (Buttons)

ESP32-S3-BOX-3 正面设有两个主要触摸/物理按键（红圈与功能键）：

| 按键 | 动作 | 功能说明 |
| :--- | :--- | :--- |
| **功能键 (左侧/Boot)** | **单机 (Click)** | **切换对话/监听状态**。<br>1. **对话中**: 强制结束当前对话。<br>2. **启动时**: 如果设备正在启动且未配网，长按或点击可进入**配网模式**。 |
|  | **双击 (Double Click)** | **切换回声消除 (AEC) 模式**。<br>在“本机AEC”与“关闭”之间切换。开启后可增强嘈杂环境下的识别率。 |
| **静音键 (右侧/红圈)** | **按下 (Press)** | **硬件静音**。设备麦克风物理断开，此时设备无法听到任何声音。 |
|  | **弹起 (Release)** | **解除静音**。恢复麦克风拾音，并自动重置语音识别模块。 |

## 2. 联网与配对 (Network Configuration)

初次使用或更换网络环境时，需要给设备配置 WiFi。

### 2.1 进入配网模式
1.  **自动进入**: 如果设备当前没有保存任何有效的 WiFi 信息，上电启动后会自动进入**配网模式**。
2.  **手动进入**: 如果已经配过网但需要更换，请在设备启动过程中（屏幕显示 Logo 或初始化时）点击**功能键**。屏幕将提示“进入配网模式”。

### 2.2 配网步骤 (热点配网)
当屏幕显示 **"请连接到热点: SmartAgent-XXXX"** 时：

1.  **连接热点**:
    *   拿出手机或电脑，搜索 WiFi 列表。
    *   找到名为 **`SmartAgent-xxxx`** (xxxx为随机字符) 的热点并连接。
2.  **配置页面**:
    *   连接成功后，手机通常会自动弹出配置页面。
    *   如果没有弹出，请打开浏览器输入屏幕上显示的地址（通常为 `192.168.4.1`）。
3.  **输入密码**:
    *   在网页中选择您家里的 WiFi 名称。
    *   输入正确的 WiFi 密码。
    *   点击“保存”或“连接”。
4.  **等待重启**:
    *   设备收到密码后会自动尝试连接网络。
    *   连接成功后，屏幕右上角的 WiFi 图标会亮起，并且设备会自动同步时间。

## 3. 注意事项 (Precautions)

1.  **供电要求**: 请使用稳定的 5V USB Type-C 供电。供电不足可能导致扬声器破音或设备反复重启。
2.  **防误触**: 红色圆圈为静音键，如果发现设备呼叫无反应，请检查该按键是否处于按压状态（静音状态）。
3.  **使用距离**: 最佳唤醒距离为 0.5米 ~ 2米。环境越安静，识别效果越好。
4.  **无法唤醒**:
    *   检查是否静音。
    *   尝试双击功能键切换 AEC 模式（某些噪声环境下需调整）。
    *   尝试重启设备。
5.  **在线升级**: 设备支持 OTA 在线升级。当服务器发布新固件时，设备可能会提示升级，请保持通电直到升级完成。

---

> **技术支持**: 如遇死机或无法恢复的故障，可尝试按一下设备侧面或背面的 **Reset (RST)** 小孔进行硬件复位。
